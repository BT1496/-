# 산업안전지도사 PC·모바일 v9

- PC: `pc-v9/index.html`
- 모바일: `mobile-v9/index.html`
- 두 화면은 `shared-v9/`의 같은 데이터와 기능을 사용합니다.
- 공개 기본 문제: 한국산업인력공단 Q-Net 2026년 공개용 A형 75문항과 최종정답.
- 개인 교재는 자료·설정에서 `private-course.json`을 불러옵니다. 개인 자료는 IndexedDB에만 저장하며 서버로 보내지 않습니다.
- 정답 확인 후 풀이·해설은 별도 버튼으로 펼칩니다. 정답 번호만 빨간색으로 강조합니다.
- 모든 과목·단원·문제를 처음부터 열람할 수 있습니다.
- 오답·즐겨찾기·메모·시청완료·학습완료는 기기별로 저장됩니다. 기록 내보내기·복원으로 기기 간 이전합니다.

## 검토 상태

문항별 현재 법령 대조가 완료되지 않은 문제는 출제 당시 정답으로 표시합니다. 교재 원문을 개정 완료 문제라고 표시하지 않습니다. 150개 단원은 기존 이론을 유지하며 상세 개편 완료를 의미하지 않습니다. 출제빈도는 주제 분류가 검증된 문항만 집계하고 나머지는 분석 중으로 표시합니다. 확인된 안전25시 3과목 영상만 연결하며 확인되지 않은 2과목 영상은 표시하지 않습니다.

상업 교재 PDF·교재 해설·개인학습자료는 공개 저장소에 포함하지 않습니다. 이전 앱 파일은 변경하지 않았습니다.
