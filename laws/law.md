# 산업안전보건법 — 현행본 확인 안내

검토 기준일: 2026-10-18.

기존 이 경로의 파일은 시행일자 2027-01-08인 예정본이므로 현행 전체 원문으로 사용하지 않습니다. 기존 파일은 `future-law-20270108.md`에 보존했습니다. 해당 예정본에는 일부 조문의 별도 시행일도 있으므로 부칙을 함께 확인해야 합니다.

2026년 8월 1일 시행 법률 제21374호와 부칙을 기준으로 확인한 조문은 학습앱의 ‘법령 원문’ 화면에서 볼 수 있습니다. 전체 현행 원문은 [국가법령정보센터](https://www.law.go.kr/법령/산업안전보건법)에서 확인하세요.

문항별 현행법 검토 완료 여부는 별도로 표시합니다. 모든 문항의 개정법 전수 대조가 끝난 상태는 아닙니다.
