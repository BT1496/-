# 2027 산업안전지도사 1차 무료 PWA v5

## 핵심
- 앱은 한 번만 홈 화면에 추가
- 이후 수정은 `content/latest.json`만 교체
- 사용자는 앱에서 `업데이트 확인` 클릭
- 정답률 / 오답노트 / 피드백 메모는 브라우저 localStorage에 남으므로 콘텐츠가 바뀌어도 유지
- OpenAI API 사용 없음 → API 비용 0원

## 무료 배포
가장 간단한 방법:
1. 이 ZIP 압축을 푼다.
2. Netlify Drop에 폴더 전체를 드래그해 배포한다.
3. 생성된 주소를 공유한다.
4. 휴대폰에서 주소를 열고 '홈 화면에 추가'한다.

## 나중에 문제나 해설 수정할 때
1. 앱의 '피드백' 탭에서 수정사항 작성
2. 'GPT용 문구 복사' 버튼
3. ChatGPT 대화에 붙여넣기
4. 수정된 `content/latest.json`을 받아 기존 배포 폴더의 동일 파일과 교체
5. 재배포
6. 사용자는 앱에서 '업데이트 확인'만 누르면 됨

## 버전 규칙
내용을 수정할 때 `version`을 v5.1, v5.2처럼 반드시 올려야 앱에서 새 버전으로 감지합니다.

## 주의
`examDate`는 2027 시험일정이 공식 확정되기 전까지 예상일로 취급하세요.
